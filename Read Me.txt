A Windows-PowerShell-style terminal you can talk to. It is read-only by default: it only changes things when you
ask (updating itself, starting a game or a program, saving a report).

HOW TO OPEN:   double-click START.bat     (Python 3 must be installed)

WHAT'S NEW IN THIS VERSION
  - Screen Watch: the "watch" command (Windows only).
  - Always-on guard: "watch guard on".
  - 22 modules (new: src\20_screen_watch.py).

WHAT IS IN THE FOLDER:
  START.bat    one-click start: aligns the modules and opens Jarvis
  pwsh.py      the file that really runs (and that Jarvis checks and updates by itself). You do not need to touch it.
  src\         the code, split into 22 modules: this is where you work
  build.py     the "glue" between src\ and pwsh.py (START.bat runs it for you)

HOW TO CHANGE THE CODE:
  1) edit a file in src\   (for example src\14_news.py for the news, src\20_voice.py for the voice)
  2) double-click START.bat  ->  pwsh.py is rebuilt automatically.
     If there is a syntax error, it tells you the file and the line, and NOTHING broken is started.

WHEN JARVIS UPDATES ITSELF ("implement jarvis", data update, etc.):
  at the next START.bat the changes are copied back into src\ (a backup goes to backup\).
  If you changed src\ AND Jarvis changed pwsh.py at the same time, nothing is touched and you are told how to choose:
      python build.py --build   (keep src\)        python build.py --pull   (keep pwsh.py)

USEFUL:   python build.py --check   tells you whether everything is aligned

IF WINDOWS SAYS "UNKNOWN PUBLISHER" (SmartScreen):
  this is the standard warning for downloaded files; it has nothing to do with the code (read it: it is plain Python).
  Before extracting: right-click Jarvis.zip -> Properties -> tick "Unblock" -> OK. Or in PowerShell:
  Get-ChildItem -Recurse "C:\path\to\Jarvis" | Unblock-File

NOTES:
  - The folders jarvis_update\, jarvis_exports\ and ext\ live next to pwsh.py.
    If you had them with an older version, copy them into this folder.
  - Apart from Screen Watch, behaviour is that of v2.5.4. The 20 comment lines
    "# >>>>> JARVIS-PART ... >>>>>" are only used to put the modules back together.

SCREEN WATCH (Windows only):  "watch" tells you when someone may be looking at your screen
  (RDP, VNC, TeamViewer, Zoom and similar). It only READS what Windows reports (sessions, connections, processes,
  window titles). Type:  help watch      Its only file is its settings file, jarvis_update\screenwatch.json

ALWAYS-ON GUARD (works even when Jarvis is closed):  type  "watch guard on"  (once).
  It puts a file in your Windows Startup folder that runs the same check in the background, with no window.
  If Jarvis is open, Jarvis gives the warning (and pauses) and the guard stays silent: never two windows.
  Manage it:  watch guard | on | off (removes everything) | start | stop
  The file:  %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\JarvisScreenWatch.vbs
